ds004511 脑电分类项目｜会话更新记录
2026 年 11 月 18 日

对一名训练时从未见过的参与者，加入 AGFL 图滤波层能否提高区分两类赌博任务试次的能力？主实验使用 ds004511 的 EEG，在同一批测试试次上比较 EEGNet、EEGNet + AGFL 和零跳对照。运行命令见同目录 README.md。


一、代码来源与研究范围

最初将 Aura-aa/deception 的 main 分支克隆到 lies 目录，提交号为 53bf9e4。该版本已有逻辑回归、直方图梯度提升、随机森林和多数类基线，也提供 CSP、xDAWN、多模态融合、注意力网络、对比学习、蒸馏和可选 LLM 对照。LLM 的作用是根据数值特征预测任务标签。EEG 准备、训练和评估均可独立完成，无须 API 密钥。

随后从上游快进至 483b673。该提交引入 agfl.py、torch_benchmark.py、agfl 命令及等宽特征分组。上游默认在同一参与者内划分训练和测试试次，用 EEG 与外周生理特征训练 60 轮。以下记录的 EEG 单模态路径、嵌套验证、频带积分修正、EEGNet 和配对报告，均是在该提交之上的工作区修改。截至本记录编写时，这些修改尚未提交或推送；在另一台机器上复现实验时需要同步当前工作区。

会话前期也检查了自采数据。记录器保存了 1,297 个一秒窗口，包含 20 通道 EEG、4 通道 EMG 和单声道音频。窗口数不能当作试次数。候选行为备份有 33 个已完成的正式试次，但记录器的实验标记文件为空，两套时钟的对应关系尚未核实。将重建脚本中的两种标签规则应用于这 33 个试次，存档规则与实际报告是否符合结果的规则有 11 次给出不同答案。因此，本次实验限定为 ds004511 内部评估。自采数据未并入训练或测试，项目也未新增 .npz 导入器或跨数据集推理命令。


二、先把每一行行为记录对应到正确的 EEG 片段

涉及 preparation.py、features.py、cli.py。

• 只取 ses-01、task-GG、run-01。行为日志中的 Probable_Truth 映射为 y=0，Probable_Lie 映射为 y=1，其余条件记录剔除原因。指标衡量模型与实验任务标签的一致程度，个体是否有主观欺骗意图并未得到独立验证。
• 数据准备和对齐模板现在默认只要求 Subject_ID、Trial_ID、EEG_Onset 和 Event_Phase。每个试次必须对应一个经核对的起点，各参与者使用同一个事件阶段。原始 EEG 中反复出现同名 Sync 标记，准备程序不会自动选取最近标记来替代已核对的起点。
• 修正行为 TSV 行次序与呈现次序不一致时的处理。先按 Trial_Order 的数值排序，再检查同一人的起点是否严格递增。QC_Source_Row 仍能追溯原文件行号。这样试次 2 正确排在试次 10 之前。
• EEG 单独准备时可完全省略生理记录与 Physio_Onset。将来使用 EMG 时，通过 --include-physiology 读取生理记录，并为同一事件提供 Physio_Onset。特征模型可用 --input-mode eeg_emg 选择 EEG 和 EMG。这里实现的波形 EEGNet 只接收 EEG。

沿用的 EEG 处理也影响结果解释。程序取参与者共同可用的具名 EEG 通道，剔除坏道、眼电和设备辅助通道。按记录条件使用 50 Hz 陷波、1–45 Hz 零相位带通和抗混叠重采样。每个默认窗口从事件前 0.2 s 到事件后 1.5 s，滤波另需两侧各 5 s 的连续样本。触及边界、坏段或非有限值的试次会写入 dropped_trials.csv。

在默认采样率 f_s=256 Hz 下，含首尾采样点的长度为
    T = round(1.5 × 256) − round(−0.2 × 256) + 1 = 436。
epochs.npy 的三个轴依次为试次、电极和时间。零相位滤波使用事件之后的样本，因此本项目报告的是离线、事件对齐的分类性能。


三、修正短时间窗的频带功率

涉及 features.py，EEG 特征版本升级为 3。

特征模型使用以下四个事件后时间窗（单位为秒）
    [0.1, 0.4)、[0.4, 0.8)、[0.8, 1.2)、[1.2, 1.5)。
四个频带为 theta [4,8)、alpha [8,13)、beta [13,30)、gamma [30,45)，单位为 Hz。两者组合成 16 个组，每组含各电极的对应功率。原代码对带内频点作梯形积分。在默认设置下，第一和第四时间窗的 theta、alpha 各只有一个带内中心频点。单点梯形面积恒为零，四组特征因此失去试次间差异。

新方法用 Welch 单边功率谱密度 S_k 乘以频点覆盖频带的实际宽度。设窗长为 N，频率分辨率 Δf=f_s/N，第 k 个频点的覆盖区间为 I_k=[f_k−Δf/2, f_k+Δf/2]，并裁剪到 [0,f_s/2]。对于频带 B=[l,h)，
    w_k = max(0, min(h, I_k 的右端) − max(l, I_k 的左端))，
    P_B = Σ_k S_k · w_k，
    特征 = log10(max(P_B, ε))。
这里 w_k 的单位为 Hz，ε 取浮点数的最小正规正值，用来处理零功率。即使带内只有一个中心频点，只要相应频率区间与频带重叠，信号仍可贡献功率。将波形振幅加倍时，功率应变为 4 倍，对数功率应增加 log10(4) ≈ 0.60206。这个关系用于回归测试。新积分保留现有频率分辨率，短窗仍只能粗略区分相近频率。

旧数据包若保存了 epochs.npy，可用 features 命令重新生成第 3 版特征。只有表格时无法恢复丢失的谱信息。重新写出表格也不会将其标为新版。agfl 会提示已知旧版数据重新提取特征。eegnet 直接读取波形，不依赖这 16 组频谱特征。


四、特征模型中的 AGFL 如何比较

涉及 agfl.py、torch_benchmark.py、cli.py。图传播本身来自上游，本次修正了输入选择、对照初始化、分组检查、单个 EMG 节点和验证方式。

agfl 默认使用 EEG，比较 none 和 inter。程序检查 16 个时间窗–频带组是否齐全、组内电极集合是否一致。在每个训练分区内填补缺失值、标准化，并把各组变为等宽向量，默认宽度 d=16。宽组用训练数据拟合 PCA，窄组补零。第二次 PCA 在训练分区的图前编码上拟合，保留至少 95% 的方差。各组实验使用同一套投影基和同样初始化的线性分类头。

设一次试次有 n 个节点，编码矩阵 H_enc 的形状为 n×d。记 W_q、W_k、W_v、W_o 为可学习矩阵。
    H = LN(H_enc + b)，Q = H W_q，K = H W_k，V⁽⁰⁾ = H W_v
    S = Q Kᵀ / √a
    A 的第 i 行 = 对该行允许的、得分最高的 κ 个邻居做 softmax，其余边权为 0
    U⁽ˡ⁾ = A V⁽ˡ⁻¹⁾
    Vᵢ⁽ˡ⁾ = Uᵢ⁽ˡ⁾ · ‖Vᵢ⁽⁰⁾‖₂ / (‖Uᵢ⁽ˡ⁾‖₂ + 10⁻⁶)
    α = softmax(c)，输出 = LN(H + (Σ_{l=0}^L α_l V⁽ˡ⁾) W_o)。
LN 表示在节点的特征维度做层归一化。邻接矩阵逐试次计算，允许有向边，排除自环，行和为 1，同一层中的各跳复用 A。默认注意力宽度 a=16，传播 L=2 跳，最多 κ=5 个邻居。

none 直接将编码送入投影与分类头。k0 保留可学习变换、残差和归一化，使用 V⁽⁰⁾，不在节点间传递消息。intra 限制在模态块内传播。inter 允许所有节点互连，仍由 top-k 选择实际邻居。combined 依次执行两种传播。纯 EEG 时只有一个模态块，intra 和 inter 的候选边相同。选用 eeg_emg 时，所有 EMG 特征组成一个节点。修正后该节点在 intra 步直接通过，仍可在 inter 步与 EEG 节点交换信息。


五、加入直接学习波形的 EEGNet

新增 eegnet.py、waveforms.py，接入 torch_benchmark.py 和 cli.py。波形可保留功率汇总会丢失的信息，例如两段极性相反的 EEG 波形具有相同功率。新增 eegnet 命令用于比较在学习时空表示后，图传播还能贡献多少。

输入为 X∈ℝ^(B×C×T)，B 为批大小，C 为 EEG 通道数，T 为采样点数。标准化参数只由当前训练分区的 N_train 个试次估计。
    μ_c = Σ_{i,t} X_{i,c,t} / (N_train · T)，
    σ_c² = Σ_{i,t} (X_{i,c,t} − μ_c)² / (N_train · T)，
    Z_{i,c,t} = (X_{i,c,t} − μ_c) / σ_c。
统计量以 float64 分批累积，两种划分均使用训练统计量，模型按需读取 float32 小批次。训练中恒定的通道在验证和测试时保持为零。波形预处理不需要将整份 EEG 一次载入内存。

EEGNet-8,2 实现了 8 个时间卷积滤波器，每个时间滤波器配 2 个跨电极的深度空间滤波器，得到 16 维表示。随后使用深度可分离时间卷积。卷积块使用批归一化、ELU、平均池化和 dropout（默认 0.5）。验证和测试时冻结批归一化的运行统计量并关闭 dropout。

针对默认 1.7 s 短试次，第二次池化比原参考实现短，给图层保留更多时间位置。在 256 Hz、T=436 时，第一时间卷积核长 128，第一次池化宽 8，降至 32 Hz。第二时间卷积核长 16，第二次池化宽 4。输出节点数为
    n = floor(floor(436 / 8) / 4) = 13。
每个节点是一个按时间顺序排列的 16 维学习表示。图层置于卷积编码器与展平操作之间。13×16=208 个值进入线性二分类头。每次优化更新后，将每个空间滤波器的 L2 范数限制在 1 以内，将分类头每一行权重的 L2 范数限制在 0.25 以内。

默认比较普通 EEGNet（none）、EEGNet + AGFL（inter）、EEGNet + 零跳层（k0）。这三个模型端到端独立训练，在同一折与同一种子下使用相同的编码器和分类头初值、样本顺序、dropout 随机序列以及候选训练轮数。主比较 inter−none 衡量加入整层的效果，inter−k0 进一步考察节点间消息传播的贡献。EEGNet 参考文献为 Lawhern 等，2018，DOI 10.1088/1741-2552/aace8c。


六、训练、验证与测试如何分开

涉及 torch_benchmark.py、cli.py。特征模型与 EEGNet 共用评估逻辑。

1. 外层默认采用按人留一法（LOSO）。设全部参与者的集合为 S。每次留出一个 s 作为测试者，外层训练集合是 S 去掉 s。一个人的所有试次都随其进入同一外层测试折。
2. 仅在外层训练参与者中做分组交叉验证，默认 3 折，参与者较少时取可用折数。每个内层训练分区单独拟合预处理，重新初始化模型和优化器。同一条训练轨迹在候选轮数 20、40、60 处评估。各配置、各随机种子分别选择轮数。
3. 对候选轮数 e 汇总所有内层验证预测。记 C_y(e) 为类别 y 的正确数，N_y 为该类总数，则
       BA_val(e) = ½ · [C_0(e)/N_0 + C_1(e)/N_1]。
   选择 BA_val 最大的 e，平分时取较小的轮数。随后用全部外层训练参与者重新拟合预处理和模型，只在选定轮数上预测外层测试者。指定 --epochs 可固定轮数。--grouping within 评估的是同一人的新试次，采用预设训练轮数。
4. 模型使用 Adam、默认学习率 0.001。训练类权重 w_y=N_train/(2n_y)。对于小批次 M，
       Loss = −(1/|M|) Σ_{i∈M} w_{y_i} · ln p(y_i | X_i)。
   预测概率 p(y=1|X) ≥ 0.5 时判为 1。特征模型默认全批量训练、weight_decay=0.01。EEGNet 默认每批 32 个试次、weight_decay=0，可用 CPU 或 CUDA。--shuffle-labels 可在外层训练集的各参与者内部置换标签，检验随机标签对照，外层测试标签始终保持原值。


七、按人配对报告结果

涉及 metrics.py。报告仍提供准确率、宏平均 F1、可用时的 ROC AUC，以及成功预测覆盖率。核心结果是相同种子、测试折、参与者和 Trial_ID 上两模型的平衡准确率之差。

设配置 A 是参照模型，B 是待比较模型，s 是参与者，r 是随机种子的索引。
    BA(s,r) = ½ · [TN/(TN+FP) + TP/(TP+FN)]，
    Δ(s,r) = BA_B(s,r) − BA_A(s,r)，
    Δ总体 = (1/|S*|) Σ_{s∈S*} [(1/|R|) Σ_{r∈R} Δ(s,r)]。
S* 只包含同时出现两个类别、且每个指定种子均有完整配对预测的参与者。缺少一类时，双类别 BA 记为未定义。先在同一人内平均种子，再给每个人相同权重，避免试次数较多的人主导总体差值。

例如，若某人普通 EEGNet 的两类召回率为 0.8、0.6，带图模型为 0.8、0.7，则该人的 BA 分别为 0.70、0.75，配对差为 +0.05，即提高 5 个百分点。此例只解释单位，并非实验结果。

predictions.csv 保存逐试次预测，folds.csv 标明外层参与者，validation.csv 保存内层候选轮数的评分，selection.csv 记录各折最终选择。paired_comparisons.csv 保存逐人逐种子的差值。metrics.json 同时给出总体差值、参与者总数和可评分人数。run.json 与相应的 eegnet_config.json 或 agfl_config.json 可用于核查实验设置。当前命令输出交叉验证记录，不导出用于部署的训练权重。


八、核查记录与尚未验证的部分
